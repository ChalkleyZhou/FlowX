# 测试与质量模块实施验收记录

日期：2026-11-04。实现分支：`codex/quality-execution`。

## 已实现

- 需求直达测试设计，指定项目/共享用例库与模块，稳定检索和截断提示，人工补选；测试数据、适用端和选例依据进入冻结快照。
- 提测显式准备，基于确认设计检查、冻结范围和已完成研发流程；有冒烟快照时仍需通过原冒烟门禁。完成准备后的范围不可修改。
- 功能初测和缺陷回归显式映射目标端，本地原子领取、分批回传、幂等重试、续租、释放和取消；默认续领仅包含未完成项。
- 本地交接使用短期一次性票据，检查仓库映射、远端、分支、HEAD 与业务改动；交接失败释放范围。服务端取消不会宣称设备已停止。
- 平台独立执行详情、静默轮询、逐例结果和证据、失败/阻塞关联缺陷、创建新回归轮次；历史执行事实保留。
- 失败和阻塞也可生成阶段/最终报告；认证预览与 HTML 下载，不可变报告历史，明确基线和回归替代。多次修复允许无环回归链或最终回归显式替代多次历史失败。
- 任务报告与状态共享冻结范围口径，漏测用例和已知适用端保留在分母。完整回归裁定不被后续局部报告撤销。

## 本地工具适配

结论：**需要适配，已在同一变更中实现**。

| 消费者 | 实际适配 |
| --- | --- |
| Web / API | 设计选例、提测准备、正式轮次、领取/回传/控制、报告和缺陷关联契约同步 |
| `@flowx-ai/protocol` | 增量质量能力、进度与报告、质量启动 purpose；旧冒烟类型保持 |
| MCP | 唯一 `mcp.ts` 中暴露测试设计、候选/冒烟编辑、`flowx_test_requests`、功能/回归执行、控制和报告工具 |
| CLI / loopback / IDE Adapter | 复用既有启动命令与本地服务，新增 `quality-test` purpose、任务/会话绑定与失败释放 |
| Skill | 安装 `flowx-local-test` 模板，要求真实执行、证据与结果回传；人工确认和 prepare 必须明确操作 |

服务端与本地包可以分别升级。新增工具先检查能力；旧服务端不支持时返回明确错误，不退回冒烟执行。旧 `LOCAL_SMOKE`、冒烟工具、门禁和旧人工模式保留；旧人工录入不能覆盖新 `LOCAL` 结果。使用新能力需要配套本次源码构建的服务端和本地包，升级后重载 IDE MCP；本次不发布 npm。

## 自动化验证

验证使用隔离 worktree 和临时 SQLite 数据库，没有对开发/生产数据库执行迁移。

- Prisma client 生成；增量迁移在保留旧质量数据的临时数据库验证，检查默认值与外键。
- 真实 MCP client → HTTP → Nest 严格 DTO → SQLite：领取、四类结果分批回传、同键重试与内容冲突、续租、完成、关闭与失败报告。
- 真实 SQLite 并发领取、执行人归属、旧入口拒绝正式会话、释放后续领剩余项、旧会话迟到结果拒绝。
- 真实修复交付新 SHA → 回归 → 显式替代汇总，核对当前状态、初测失败及历史报告；后续局部报告不撤销完整裁定。
- 真实 HTTP / SQLite 提测准备：revision 与幂等、研发状态复查、冻结范围、冒烟门禁与旧准备入口兼容。
- Web 自动化覆盖连续准备、范围操作、显式映射、异步响应隔离、静默轮询、启动反馈、租约控制、报告 payload、认证预览及 URL 释放。
