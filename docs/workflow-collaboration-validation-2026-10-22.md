# 工作流接续与端云多人协同验证记录

日期：2026-10-22。依据：已确认的 [协同方案](superpowers/specs/2026-10-22-workflow-collaboration-design.md) 与 [实施计划](superpowers/plans/2026-10-22-workflow-collaboration.md)。本记录覆盖本轮实现；`local-validation-2026-10-22.md` 保留实施前问题复现记录。

## 环境与数据边界

- 代码分支：`codex/workflow-collaboration`，基线 `f1c1fdc`。
- Web：`http://127.0.0.1:4173`；API：`http://127.0.0.1:3000`。最终全仓构建后，已用最新 API 构建重启并复查页面。
- 浏览器使用开发库备份的再次隔离副本，保留既有登录；只在该隔离库增加明确标记的合成提测、版本和双端冒烟记录。未修改原业务数据库，未提交数据库、登录态或运行数据。
- 竞争与权限验证使用测试专属 SQLite 数据库、独立 Prisma 连接及真实 Nest HTTP 边界；没有用正常业务流程制造领取竞争或强制交接。

## 验收矩阵

| 场景 | 验证结果与证据 |
| --- | --- |
| 1. 需求直接接续 | Web 回归覆盖单活跃、多活跃、无活跃、历史与错误状态。浏览器进入现有需求可继续原流程；另起流程进入原仓库/执行器弹框并显示占用范围，取消未创建重复流程。 |
| 2. 当前任务前置 | 浏览器首屏显示设计任务、执行人、执行位置、最近回报与确认后去向；切到历史 Grounding，顶部仍保持当前设计任务。后台刷新、回退中切路由与终态轮询有回归。 |
| 3. 原执行人专属回传 | 三阶段与冒烟回传核对组织及领取人；真实 HTTP 验证他人和管理员不能冒写会话、进度、产物或证据，原人可以写入。没有归属记录的历史设计稿只读。 |
| 4. 同阶段领取竞争 | 真实 SQLite 集成验证构思、设计、方案两人同时领取仅一个成功、另一个 409；原人复用、不同冒烟范围并行继续有效。 |
| 5. 端云状态可辨 | 组件测试覆盖未收到真实回报、近期回报、失联、待确认与终态。浏览器旧 RUNNING 会话显示“尚未确认本地运行状态”，未根据领取时间声称 IDE 已启动。交接表单要求停止确认与原因，浏览器仅打开后取消。 |
| 6. 冒烟多人边界 | 7 项真实数据库集成覆盖同用例竞争无孤儿、不重叠并行、越权、幂等、失败优先且证据不覆盖、旧版本、有效租约阻止汇总归档。浏览器合成双端记录显示执行人、用例范围、租约与回传结论。 |
| 7. 提测详情恢复 | 真实 HTTP 验证无报告返回 JSON `null`、报告对象及不存在 404；Web 回归覆盖局部失败保留详情、独立重试、主请求重试及迟到请求隔离。浏览器无报告正常展示，不再误报不存在。 |
| 8. 构建、浏览器与文档 | 根 `pnpm check` 通过，见下表；本地需求、工作流与提测详情已检查。README、系统设计、两份指南及 Web 镜像已同步。浏览器复查时无 error/warn 日志。 |
| 9. 位置查询与换人 | position 在他人/匿名/缺失归属时返回 `none`，只提供当前已确认上游产物；允许当前设计清单显式保留旧页面。真实 SQLite 验证释放后 B 领取新 attempt、重复释放不影响新任务、旧回传及旧兼容入口拒绝；释放与完成竞态只有一个事务成功。 |

## 浏览器证据

本轮保存了当前任务、交接确认、需求接续、仓库范围和无报告提测截图，交付回复附当前任务截图。本地页面保留供继续体验。

没有在既有业务流程上实际点击结束任务、回传新产物或生成真实报告。换人写入与竞态由隔离数据库/HTTP 集成测试验证，浏览器交接仅验证表单约束。
