# 原型快速导入自动接续实施计划

**目标：** 上传后由服务端完成 AI 整理、资料落库和工作流接续；用户只看到处理中、成功或失败。用户已明确要求取消导入确认，不增加审批。

**设计：** 保留原型材料、版本 CAS 和现有工作流快照。AI 整理成功后自动落库，未回答的问题作为方案待澄清内容，不能伪造为用户确认。复用现有工作流服务进入仓库准备及 Spec & Plan。失败保留材料可重试；旧等待确认记录打开后自动接续。前端精简为状态、失败重试、成功跳转及折叠原型资料。

- [x] API 回归测试：不填写问题即可自动落库并创建一次工作流；无仓库失败可恢复；旧任务不覆盖新修订；自动快照不伪造人工确认。
- [x] API 实现：自动保存和创建工作流，查询返回流程 ID；保持组织隔离和版本检查，更新阶段描述。
- [x] Web 回归测试：成功自动进入工作流，失败保留重试，后台轮询无闪烁，旧记录自动接续且不再出现确认表单。
- [x] Web 实现：替换原型确认界面，更新入口与列表文案。
- [x] 同步 README、使用手册及镜像、原型专题、系统设计和 CHANGELOG。
