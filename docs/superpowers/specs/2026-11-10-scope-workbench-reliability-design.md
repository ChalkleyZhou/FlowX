# 提测范围工作台与状态一致性

用户已确认：左侧只保留用例库和模块目录；右侧默认显示本次范围，可切换全部用例；勾选代表纳入，取消后即时移除并可撤销；模块操作覆盖完整模块与后代，不受列表分页限制；点击标题按需查看详情并支持上一条、下一条；自动保存仅显示轻量状态，失败回滚；AI 新用例保存到长期库放入详情，由人工操作。

## 数据与边界

- 纳入条件同时检查 action != EXCLUDE 和 resolution != REJECTED，服务端为唯一持久化事实来源。
- 现有 scope-draft 查询增加可选 view、libraryId、moduleId；旧请求保持原样。新视图由服务端分页查询，提供全范围计数。
- PATCH 增加可选 restoredCandidateIds，支持无正式定义的 AI 新用例撤销移除。补选已有候选必须恢复状态，不重复创建。
- 模块批量操作由 API 按项目/共享库权限和完整后代模块计算，沿用 scopeRevision CAS。已确认快照不再修改。
- Web 保存请求串行化，使用最新 revision，查询忽略过期响应，首屏以外刷新保留内容。保存或刷新失败必须显示真实状态，不弹成功提示。
- 详情只展示，不改变范围；列表保留目录、页码、搜索和滚动位置。

## 本地适配

复用现有能力：flowx-local/MCP/CLI 继续通过原有测试计划、领取与回传 API 工作，不消费 Web 草稿工作台；所有新增字段可选，现有 API 默认语义不变，无数据库或共享协议修改。Web 草稿浏览和撤销入口不新增 MCP tool。

## 验收

真实 SQLite 验证移除、重新查询、恢复、重复恢复、过期 revision、快照确认后拒绝、跨项目库拒绝及超过一页的模块。Web 验证取消后消失、全部视图未勾选、撤销恢复、失败回滚、连续操作和旧响应隔离。运行 Web/API test/build、pnpm check、文档镜像校验和 git diff --check。
