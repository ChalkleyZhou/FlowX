# 测试用例库树状筛选与快速新建设计

日期：2026-11-05。状态：用户已确认方案，待进入实施计划。

## 1. 目标与边界

将测试用例库页面的主筛选入口从顶部下拉选择调整为左侧树状目录，让用户按“用例库 → 模块”浏览和筛选用例，并可在模块节点旁直接新建用例。

本次只调整 Web 页面布局、筛选状态和现有创建弹窗的入口，不新增后端接口、不改变测试用例数据模型、不改变提测快照和执行记录语义。现有搜索、优先级筛选、分页、查看、编辑、删除、导入和模块管理继续保留。

## 2. 用户体验

### 2.1 页面布局

`QualityCasesPage` 使用响应式双栏布局：桌面端左侧为约 `240px` 的“用例目录”，右侧为现有测试用例列表；窄屏时两栏上下排列。

左侧树包含两级节点：

- 用例库节点：点击后筛选该库下的全部用例，并展示库的用例数量（如果接口提供）。
- 模块节点：点击后筛选该库下的指定模块用例。模块支持已有父子层级，按缩进显示。

树顶部保留“新建用例库”按钮。每个模块节点右侧显示带可访问名称的 `+` 按钮，点击后打开现有“新建测试用例”弹窗，并自动带入该模块所属的 `libraryId` 和 `moduleId`。页面顶部的“新建用例”按钮继续保留，用于未指定模块的通用创建。

右侧保留搜索、优先级筛选、分页和用例表格。选中树节点后，右侧标题显示当前节点名称；选择“全部用例”时展示当前范围内所有用例。

### 2.2 URL 与筛选行为

树选择写入 URL，复用现有 `libraryId`，并新增/复用 `moduleId`。选择用例库时清除旧的 `moduleId`；选择模块时同时写入其 `libraryId` 和 `moduleId`；切换工作区、项目范围或用例库范围时清除失效的节点筛选并回到第 1 页。搜索、优先级和分页仍保持现有 URL 语义。

模块级快速创建只负责预填弹窗，不改变当前筛选，创建成功后刷新列表并选中新用例所在的库/模块节点。创建失败沿用现有 toast 错误提示。

## 3. 数据加载与状态

- 复用 `getTestCaseLibraries` 和 `getTestCaseModules`，不新增 API 或协议字段。
- 用例库列表加载后，默认展开当前选中的库；模块按库加载并缓存在页面状态中，重复展开不重复请求。
- 模块加载期间在对应库节点下显示局部 loading，不切换右侧列表的整页 loading。
- 某个库的模块加载失败时，在该节点显示错误和“重试”入口；右侧已有用例列表保持不变。
- 没有模块时显示“暂无模块”，并提供“模块管理”入口；没有用例库时显示树空状态，同时保留“新建用例库”。
- 首屏无数据时使用现有 loading/error/empty 状态；刷新已有数据时遵循页面现有静默刷新行为，不清空内容。

## 4. 组件与实现边界

优先在 `apps/web/src/pages/quality/QualityCasesPage.tsx` 内增加树状态、节点渲染和布局组合；只有当树节点递归渲染或测试隔离需要时，才抽出小型无业务组件。使用现有 `Button`、`Card`、`Input`、`EmptyState`、`LoadingState`、图标和 `cn` 样式工具，不引入新的 UI 依赖。

`CreateCaseDialog` 增加可选的初始库/模块参数，保留现有表单校验和提交 API。弹窗打开时用初始值填充选择器；用户仍可在弹窗内调整模块。页面只负责传递筛选上下文和刷新回调，业务校验继续由现有 API 与弹窗处理。

本次影响评估：Web 页面和现有 API consumer 需要适配；API、Prisma、`packages/flowx-local`、MCP、CLI、Skill 和 `@flowx-ai/protocol` 不需要变更，因为现有接口已经支持按 `libraryId/moduleId` 查询和创建用例。

## 5. 测试计划

在现有 Web 测试基础上补充页面级行为测试，至少覆盖：

1. 点击用例库节点后 URL 写入 `libraryId` 并请求对应筛选；点击模块后同时写入 `libraryId/moduleId`。
2. 点击模块节点的 `+` 后打开创建弹窗，并预填对应库和模块。
3. 模块加载、模块为空、模块加载失败重试和没有用例库时的状态展示。
4. 创建成功后刷新列表并保留/更新正确的树节点筛选。

完成后运行 `pnpm --filter flowx-web test` 和 `pnpm --filter flowx-web build`，并执行 `git diff --check`。用户手册已有用例库操作说明，实施完成后同步补充树筛选和模块级快速新建描述，并校验 `docs/user-manual.md` 与 `apps/web/public/user-manual.md` 一致。

## 6. 验收标准

- 用户可以只通过左侧“用例库 → 模块”树筛选右侧用例列表。
- 树筛选可通过 URL 恢复，且与工作区、项目范围、搜索、优先级和分页联动正确。
- 模块节点的 `+` 能打开新建用例弹窗并自动带入所属库和模块。
- 树的加载、空状态、错误重试和窄屏布局可用，不影响原有查看、编辑、删除、导入和模块管理能力。
- Web 测试、构建和文档镜像校验通过。
